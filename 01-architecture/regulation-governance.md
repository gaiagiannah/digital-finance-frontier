# Layer 6: Regulation & Governance

## Global Frameworks

| Framework | Scope | Status |
|---|---|---|
| **FSB Crypto-Asset Framework** (Jul 2023) | "Same activity, same risk, same regulation" | Oct 2025 peer review: only 11/37 jurisdictions comprehensive |
| **US GENIUS Act** (Jul 2025) | Federal stablecoin framework; 1:1 safe-asset backing; banned Fed retail CBDC | In force |
| **EU MiCA** (Dec 2024) | Comprehensive crypto-asset regulation | Fully applicable |
| **US CLARITY Act** | Market structure for digital assets | In progress |
| **IOSCO Standards** | Securities tokenization, cross-border oversight | Joint FSB/IOSCO work ongoing |
| **CPMI (BIS)** | Stablecoin reserve backing, operational resilience, AML/CFT | Recommendations in force |
| **IMF** | "Making Stablecoins Stable" (WP/26/74, Apr 2026) | Published |
| **FATF** | Travel rule, AML/CFT for crypto | 2026 update |
| **Japan JFSA** | National crypto-asset framework | In force |
| **Singapore MAS** | Pro-innovation sandboxes; Project Guardian | Active |
| **UAE** | National blockchain strategy; VARA licensing | Active |

## Regulatory Trajectory

- **2025–2026**: Fragmentation → convergence. GENIUS + MiCA + JFSA create the first "triangular" global perimeter.
- **2027–2028**: Unified cross-border stablecoin standards; tokenized securities regulation; ISO standardization.
- **2030+**: Full interoperability standards; AI-driven compliance; programmable money with embedded regulatory logic.
