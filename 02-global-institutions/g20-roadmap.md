# G20 Cross-Border Payments Roadmap

## Overview

- **Published**: October 2021
- **Goals**: Make cross-border payments faster, cheaper, more transparent, and more accessible
- **Status (2026)**: Progress described as underwhelming; BIS and FSB have driven technical/regulatory workstreams to close the gap

## Key Targets

| Target | 2021 Goal | 2026 Status |
|---|---|---|
| Speed | 1 day or less | Agorá: 80 seconds (atomic); mBridge: real-time |
| Cost | <3% of transfer value | mBridge: 98% cost reduction vs. correspondent banking |
| Transparency | End-to-end visibility | SWIFT ISO 20022; on-chain auditability |
| Access | 70% of adults with access | Stablecoins: 400M+ users; CBDCs: 260M e-CNY wallets |

## How the Roadmap Drives Current Projects

The G20 Roadmap is the **policy umbrella** under which all current technical projects operate:
- Agorá, mBridge, Mandala → Technical implementation
- FSB Framework → Regulatory implementation
- GENIUS Act, MiCA → National implementation
