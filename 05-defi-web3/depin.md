# DePIN: Decentralized Physical Infrastructure

## Overview

DePIN (Decentralized Physical Infrastructure Networks) uses token incentives to build and operate physical infrastructure.

## 2026 Applications

| Sector | Example | Status |
|---|---|---|
| Wireless/Mesh Networks | Helium, XNET | Live; 100s of thousands of hotspots |
| Storage | Filecoin, Arweave, Sia | Live; PB-scale |
| Compute | Akash, Render | Live; GPU marketplace |
| Energy | PowerLeap, Watts | Pilot |
| Mapping | Hivemapper, OSM | Live |
| IoT | Various | Early |

## Intersection with AI

- AI agents managing physical infrastructure via DePIN tokens
- Decentralized GPU compute for AI training/inference
- Edge AI + DePIN: distributed inference at the edge
