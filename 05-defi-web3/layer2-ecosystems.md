### Technical Shift (May 2026)

Base moving **off Optimism's OP Stack** toward **in-house infrastructure**:
- Signals independence from L2 rollup providers
- Full control over sequencer, data availability, consensus
- Enables custom features (AI agent optimizations, PQC precompiles)
- Risk: Loses OP Stack ecosystem benefits (superchain interoperability)
