# Government & Law Enforcement: Crypto Investigations

## U.S. Federal Agencies

### IRS Criminal Investigation (IRS-CI)

| Dimension | Detail |
|---|---|
| Mission | Tax evasion, money laundering, darknet marketplaces, crypto-enabled financial crimes |
| Crypto Seizures | **$3.5B+** seized since 2015; $10B+ in illicit activity tracked |
| Key Unit | Cyber Crime Unit (CCU), Washington DC |
| Data Sources | On-chain analysis (Chainalysis, TRM Labs), exchange KYC (via legal process), darknet monitoring, financial records (Form 8962, 1099-DA), wire transfers |
| Investigations Performed | Tax evasion (unreported crypto gains), money laundering, darknet marketplace takedowns, market manipulation |
| What They Do with Data | SAR filings, criminal indictments, civil forfeiture, asset recovery, intelligence sharing with FBI/HSI/DEA |
| Key Cases | Darknet Marketplace Task Force (DNMDCC, 2023), Lazarus Group disruption, $225M confidence scam seizure (2025) |
| Notable | March 2026: 10 foreign nationals charged for crypto "wash trading" (market manipulation); IRS-CI + FBI undercover operation |

### FBI

| Dimension | Detail |
|---|---|
| Mission | Cybercrime, ransomware, terrorist financing, national security |
| Key Divisions | Cyber Division, IC3 (Internet Crime Complaint Center), Cybercrime Task Forces |
| Data Sources | On-chain analysis, IC3 complaints (500K+ annual), exchange cooperation, international MLAT, darknet monitoring, wiretaps (FISA), undercover operations |
| Investigations Performed | Ransomware (state + non-state), terrorist financing (Hamas, al-Qaeda, ISIS), exchange hacks, DeFi exploits, NFT fraud, Ponzi schemes |
| What They Do with Data | Criminal indictments, asset forfeiture (civil + criminal), international takedowns, intelligence products, warning bulletins |
| Key Cases | $225M confidence scam seizure (2025, with USSS), Lazarus Group (Binance 2022), Welcome To Video darknet takedown, EmpiresX Ponzi ($100M+) |
| Tools Used | Chainalysis Reactor, TRM Labs, in-house blockchain analysis, Cellebrite (device forensics), Volatility (memory) |

### U.S. Secret Service (USSS)

| Dimension | Detail |
|---|---|
| Mission | Financial crimes (primary jurisdiction), counterfeiting, fraud, cybercrime involving financial institutions |
| Key Division | Criminal Investigative Division (CID) |
| Data Sources | On-chain analysis, bank records, exchange KYC, victim complaints, financial institution cooperation |
| Investigations Performed | Crypto confidence scams, bank fraud, counterfeiting (digital + physical), identity theft, financial institution cyber intrusions |
| What They Do with Data | Criminal indictments, civil forfeiture, victim restitution, financial institution warnings |
| Key Cases | $225M crypto confidence scam seizure (2025 — largest ever), BTC-e exchange operation (2024) |
| Notable | USSS has primary jurisdiction over fraud affecting financial institutions — this makes them the lead agency for most crypto exchange fraud cases |

### Homeland Security Investigations (HSI)

| Dimension | Detail |
|---|---|
| Mission | Transnational crime, terrorism, drug trafficking, financial crimes crossing borders |
| Data Sources | On-chain analysis, international cooperation (INTERPOL, Europol), port of entry data, shipping records, exchange KYC |
| Investigations Performed | Cross-border money laundering, drug trafficking (crypto payments), terrorism financing, human trafficking, transnational fraud |
| What They Do with Data | Criminal indictments, asset seizure, international takedowns, intelligence sharing with allied agencies |
| Key Cases | EmpiresX Ponzi scheme (with FBI, IRS-CI), cross-border crypto laundering, darknet drug markets |
| Notable | HSI is the DHS investigative arm — handles cases with international nexus. Works alongside FBI, IRS-CI, DEA in joint task forces |

### Joint Task Forces

| Task Force | Members | Focus |
|---|---|---|
| **DNMDCC Task Force** (2023) | IRS-CI, HSI, DEA, USPIS, FBI Cyber | Darknet marketplaces + digital currency crimes |
| **Crypto Crimes Task Forces** (local) | FBI + USSS + IRS-CI + HSI + local US Attorney | Regional crypto fraud |
| **Homeland Security Task Forces** | HSI + FBI + IRS-CI + DoD | Transnational + national security |
| **FinCEN** | Interagency | SAR/CTR analysis, intelligence sharing, pattern detection |

### How They Get Data

| Source | Method | Legal Authority |
|---|---|---|
| On-chain data | Public (no warrant needed) | First Amendment (public information) |
| Exchange KYC | Subpoena / warrant / CLOUD Act | 18 U.S.C. § 2703; CLOUD Act |
| Bank records | Subpoena / warrant | BSA; 12 U.S.C. § 1820 |
| Device forensics | Search warrant (physical) | Fourth Amendment |
| Communications | Wiretap warrant (FISA) / SCA | 18 U.S.C. § 2511; SCA |
| Dark web | Undercover operations / Tor | First Amendment (public) + 18 U.S.C. § 980 |
| International | MLAT / CLOUD Act / bilateral agreements | 28 U.S.C. § 1782; CLOUD Act |
| Financial intelligence | FinCEN SAR/CTR analysis | BSA; 31 U.S.C. § 5311 |

### What They Do with the Data

1. **Criminal prosecution**: Indictments, trials, sentencing
2. **Civil forfeiture**: Seizing crypto assets without criminal conviction
3. **Asset recovery**: Returning funds to victims
4. **Intelligence products**: Warning bulletins, threat assessments
5. **Regulatory referrals**: Passing cases to SEC, CFTC, FinCEN
6. **International cooperation**: MLATs, joint investigations, INTERPOL
7. **Policy development**: Informing legislation and regulation
