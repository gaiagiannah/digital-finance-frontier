# G7 Corridor

## Infrastructure

| Project | Function | Status |
|---|---|---|
| Project Agorá | Tokenized deposits + CBDC reserves; atomic multi-currency settlement | RVT complete (Jul 2026); scaling to production |
| ECB Pontes | Connect DLT to TARGET2 | Pilot late 2026 |
| ECB Appia | Long-term tokenized CBDC framework | Design; report 2028 |
| SWIFT Blockchain Ledger | Shared ledger for tokenized deposits | Live (Jul 2026); 17 banks |
| TCH Network | US tokenized deposit utility | Build; target H1 2027 |
| Canton Network | Privacy-preserving institutional DLT | Live; top fee generator Q1 2026 |
| JPMorgan Kinexys | Proprietary tokenized payment + asset platform | Live on Base + Canton |

## Philosophy

Private-led innovation with public settlement anchor. Preserves correspondent banking relationships while adding tokenized rails. G7-aligned regulatory perimeter (GENIUS Act, MiCA, FSB framework).

## Key Advantages

- Multi-stakeholder governance (banks + central banks + private sector)
- Privacy-preserving (Canton, ZK proofs)
- Regulatory alignment (GENIUS, MiCA, FSB)
- Preserves existing correspondent banking (incremental, not disruptive)
- Open to public blockchain integration (Base, Ethereum)

## Key Risks

- Complexity: Multiple overlapping systems (Agorá + Canton + TCH + SWIFT)
- Slow decision-making (multi-party consensus)
- China/Gulf corridor may be faster (state-directed)
- Fragmentation within G7 (US vs. EU regulatory differences)
