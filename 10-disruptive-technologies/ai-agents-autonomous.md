## The x402 Protocol

- HTTP 402 "Payment Required" — enables AI agents to pay for services on-chain
- Agent requests data → receives 402 → pays in stablecoin → receives data
- No API keys, no accounts, no human intervention
- First production deployment: Coinbase Base (2026)

## Safety Architecture

- Bounded LLM Orchestration (Arcifa et al., 2026): Smart contract safety gates
- Circuit Breakers: Hard limits on agent actions
- Auditability: All actions logged on-chain (Phiri, 2025)
- Human-in-the-Loop: Approval required above threshold
- Kill Switch: Emergency halt for all agents
